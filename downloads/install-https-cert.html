Trust the portal HTTPS certificate

Install this once on each phone so the Nutrition BNS app can use https://100.112.56.88 without certificate errors.

Download certificate (.cer) Download (.crt)
Android
  1. Open the downloaded file (Chrome → Downloads).
  2. Choose CA certificate / VPN & app user certificate when asked.
  3. Confirm install. Unlock the phone if prompted.
  4. Open the Nutrition BNS app and sign in.

Settings path (varies by brand): Settings → Security → Encryption & credentials → Install a certificate → CA certificate.

iPhone / iPad
  1. Open the .crt link in Safari and allow the profile download.
  2. Settings → Profile Downloaded → Install.
  3. Settings → General → About → Certificate Trust Settings → enable full trust for this cert.
